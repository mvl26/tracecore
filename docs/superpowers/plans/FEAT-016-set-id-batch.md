# FEAT-016 Cấp Set ID GIAI hàng loạt (≤ 100), in thẻ kim loại/nhãn khay, in lại có lý do, vòng đời Set Unit & lịch sử — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** R02/R10 cấp Set ID cho bộ vật lý trên Desk (SCR-03): chọn loại bộ (đã có BOM hiện hành), số lượng 1–100, khoa sở hữu, cơ số tối đa, nguồn bộ (mới / bộ đang lưu hành có số chu trình ước tính); hệ thống cấp cho mỗi bộ một Set ID GS1 GIAI (AI 8004) duy nhất trong **một** transaction, tạo Set Unit trạng thái Mới tạo, ghi `Code Registry`, rồi xếp hàng in thẻ kim loại và/hoặc nhãn khay DataMatrix ra máy in nhãn qua đường server (A-05). Máy in lỗi không làm mất Set ID và không sinh mã mới; in lại bắt buộc lý do và đếm số lần in; R04 quét kiểm tra thẻ sau khi gắn. Form Set Unit hiện số chu trình đã dùng/tối đa/còn lại, Cycle ID hiệu lực, và lịch sử vòng đời (đổi trạng thái do step gate, cổng, in thẻ, gói); bộ Mới tạo hoặc Hết vòng đời được thanh lý có lý do, mã không bao giờ cấp lại.

**Architecture:** Dịch vụ lõi `tracecore/core/`: `code_registry` (cấp Set ID có chặn hết dải số và tiền tố demo, tổng quát hóa `etching_prefix_block`), `gs1` (tách tiền tố/serial của Set ID), `print` (`render_label` tổng quát cho nhãn DataMatrix theo `Label Template`, `render_object` thành vỏ mỏng), `print_server` (`dispatch_many`: một background job gửi tuần tự cả lô, dừng ở lỗi mạng đầu tiên), `step_gate` (`init_unit` khởi tạo trường vòng đời khi cấp, `dispose`, lý do sự kiện vào Audit Log). Module Frappe `Instrument` (M1): package `tracecore/instrument/` thêm `set_units.py` (kiểm điều kiện, cấp lô, thanh lý, lịch sử vòng đời) và `set_tags.py` (ngữ cảnh thẻ/nhãn, hàng đợi in, đếm in, in lại, quét kiểm tra, CSV khắc). **Không thêm DocType**: Set Unit thêm 3 trường, `Label Template.label_object` thêm 2 giá trị, `Print Job` thêm index. RPC mỏng ở `tracecore/v1/set_unit.py` (GET đọc, POST `@idempotent`). Desk form + list Client Script (ADR-002). Không import chéo M1–M10: M1 đọc `Pack`/`Step Gate Result` theo tên DocType.

**Tech Stack:** Frappe v15 (`getseries`, savepoint, `frappe.enqueue`, `track_changes`), `pylibdmtx` (đã có: `gs1.encode_datamatrix_png`/`decode_datamatrix_png`), ZPL `^BXN` qua `gs1.zpl_datamatrix`, `socket` stdlib (đường in server có sẵn), Python 3.11, Desk Client Script, Playwright for Python (chỉ kiểm tay, xem G17).
