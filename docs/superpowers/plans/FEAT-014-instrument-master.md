# FEAT-014 Danh mục dụng cụ đơn lẻ (ảnh thực tế, Spaulding, IFU, phương pháp tương thích, phiên bản) + ngưỡng bảo dưỡng + mã GIAI khắc laser (bật/tắt) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** R02/R10 khai báo dụng cụ đơn lẻ trên Desk (SCR-01) với mã duy nhất (gợi ý mã kế tiếp khi trùng), tên, hãng, model, ảnh thực tế, phân loại Spaulding, IFU, phương pháp tiệt khuẩn tương thích (đổi thì lên phiên bản và cảnh báo mọi BOM đang dùng), cơ số tối đa (trống = "Chưa xác định" + báo cáo cần bổ sung), giá trị, nhóm, Item tùy chọn; cấu hình ngưỡng bảo dưỡng theo dụng cụ hoặc theo nhóm, khởi tạo bộ đếm từ lần bảo dưỡng gần nhất; khi bật tính năng, cấp mã GIAI khắc laser cho dụng cụ. Trạm lấy ảnh thu nhỏ qua `tracecore.v1.instrument.get_image`.

**Architecture:** Module Frappe `Instrument` (M1, đã đăng ký): mở rộng DocType `Instrument` có sẵn (stub FEAT-018) + child mới `Instrument Compatible Method` (đã nêu trong architecture §5.3.1) + `Instrument Group` (mới, A-06); package Python `tracecore/instrument/` thêm `catalog.py` (mã, trạng thái), `versions.py` (phiên bản + cảnh báo BOM), `media.py` (ảnh/IFU/thumbnail), `thresholds.py` (ngưỡng hiệu lực); `maintenance.py` (FEAT-018) chỉ đổi nguồn ngưỡng và thêm hàm khởi tạo/tăng bộ đếm. Cờ tính năng ở Single `TraceCore Settings` (module `TraceCore`, A-06). Mã GIAI dụng cụ sinh tại server qua `core.gs1` + `core.code_registry`. RPC mỏng ở `tracecore/v1/instrument.py` (đọc) và `tracecore/v1/instrument_admin.py` (ghi từ Desk). Giao diện: Desk form + Client Script (ADR-002). Không import chéo M1–M10: đọc `Pack`/`Instrument Set Type` theo tên DocType; M2/M8 gọi M1 qua hook (`core.extension.run`).

**Tech Stack:** Frappe v15 (`File`, `Comment`, Script Report), Pillow (đã có trong Frappe: kiểm ảnh, thumbnail, `ImageOps.exif_transpose`), `pylibdmtx` (đã có: xem trước DataMatrix GIAI), Python 3.11, Desk Client Script, Playwright for Python.

**Spec:** `docs/implementation-plan.md` §3 dòng FEAT-014 và ghi chú stub §5.3 ("FEAT-014/015 thêm validation, phiên bản, UI"); `docs/srs.md` FR-M1-01 (.1–.6), FR-M1-02 (.1–.4), FR-M1-09 (.1–.6), FR-M8-01.1, FR-M9-11.1, A-02 (D5 ngưỡng chặn), OQ-05 (D6), OQ-07, OQ-22; `docs/use-cases.md` UC-01 (luồng chính, A1, A2, E1–E3); `docs/ux-foundations.md` SCR-01 (WEB Master Form); `docs/architecture.md` §5.3.1 M1 (Instrument, Instrument Maintenance, ghi chú A-02), §5.3.2 ERD, §8.3 (thumbnail 320 px), R-08 (IFU ≤ 20 MB, ảnh ≤ 5 MB), ADR-003 (dữ liệu đọc offline), ADR-004 (GIAI tại server), ADR-008 (Audit Log), ADR-009 (Item tùy chọn). Nền: FEAT-001/018/002/038/005 (`Code Registry`, `gs1.parse_scan`, `maintenance.py`, `bom.lines`, hook `tracecore_pack_*`, `reject_block`, `@idempotent`).

FR/BRU đáp ứng: FR-M1-01 (khai báo, trạng thái Đang dùng, chọn được khi lập BOM), FR-M1-01.1 (thiếu trường bắt buộc), .2 (cơ số Chưa xác định + báo cáo), .3 (phiên bản khi đổi phương pháp + cảnh báo BOM), .4 (trùng mã + gợi ý), .5 (IFU > 20 MB), .6 (ảnh tại trạm: dữ liệu + RPC thumbnail; T4 dùng ngay, T1/T3 do FEAT-019/020 hiển thị); FR-M1-02 (.1 tùy chọn + duy nhất, .3 bật/tắt không gián đoạn T1→T7; .2/.4 → FEAT-020, xem I17); FR-M1-09 (ngưỡng theo dụng cụ/nhóm, khởi tạo bộ đếm), .1 (ngưỡng trống → không nhắc), .2 (hàm tăng bộ đếm khi giải phóng, FEAT-023 gọi); .3–.6 đã có ở FEAT-018 (chỉ đổi nguồn ngưỡng, giữ nguyên quy tắc D5); BRU-REP-014; BRU-ID-001 (GIAI không cấp lại, áp cho mã dụng cụ).
