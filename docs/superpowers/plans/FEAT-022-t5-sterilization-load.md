# FEAT-022 T5 Nạp mẻ tiệt khuẩn (Sterilization Load) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tại trạm T5 (SCR-09 STN, SCR-35 PDA), R05 quét QR máy tiệt khuẩn → chọn chương trình → quét nối tiếp Cycle ID từng gói (kiểm cổng T4 Đạt, tương thích, dung tích, không thuộc mẻ khác) → Hoàn thành nạp → hệ thống sinh Load ID `ME-YYMMDD-NN`, chuyển gói sang Trong mẻ, mẻ sang Đang chạy, in nhãn QR mẻ; quét mã mẻ để xem hồ sơ và nhập tay dữ liệu chu trình theo `Program Parameter` có ảnh bản in, tick xác nhận và quét thẻ.

**Architecture:** DocType `Sterilization Load` (submittable) + child `Load Pack` ở module `Reprocessing` (M2); dịch vụ `tracecore/reprocessing/loading.py` (nạp mẻ), `load_data.py` (nhập tay), `load_label.py` (nhãn). M2 không import M5: điều kiện "máy sẵn sàng" do `tracecore/equipment/readiness.py` cung cấp qua hook `tracecore_equipment_ready` (stub đến FEAT-040), Equipment/Process Program đọc bằng tên DocType. Nạp mẻ không lưu nháp ở server: `add_pack` chỉ kiểm, `complete` kiểm lại toàn bộ dưới khóa hàng rồi mới sinh mã (BRU-REP-016). FEAT-022 chỉ **kiểm** cổng T5 (`step_gate.check(su, "T5")` ⇒ T4 Đạt); ghi kết quả T5 là việc của FEAT-023 khi giải phóng (ADR-005).

**Tech Stack:** Frappe v15, Python 3.11, Page `station` (JS thuần, như `station_t4.js`), station agent `POST /print`, Playwright for Python.

**Spec:** `docs/implementation-plan.md` §3 dòng FEAT-022 (+ ranh giới FEAT-023/024/040); `docs/srs.md` FR-M2-09 (.1–.6), FR-M2-10 (.1–.4), FR-M2-24.1/.3/.5, FR-M2-25 (T5 cần T4 Đạt), FR-M2-00.1/.2, FR-M5-02.2, FR-M5-06 (hiện lý do khóa); `docs/use-cases.md` UC-09 (luồng chính 1, 2, 4, 5, 6; A3; E1, E2, E4); `docs/ux-foundations.md` SCR-09, SCR-35; `docs/design.md` §4.2 scan-box *locked*, §4.4 gate panel, §4.7 alert, §4.8 badge "Cần xem xét", §4.13 modal, §4.16 actions bar, §4.18 form grid, §4.19 states; `docs/architecture.md` §5.3.1 DT-LOAD, §5.3.3 `ME-.YY.MM.DD.-.##`, §6.2 sequence nạp mẻ, ADR-003/005/006/007, A-04 (handoff `param_schema`). - Thứ tự kiểm khi quét gói (dừng ở lỗi đầu tiên): trạm (`require_step` T5) → máy sẵn sàng (L5) → chương trình thuộc máy và đang dùng → mã quét là gói (`gs1.parse_scan` type `pack`) → Pack tồn tại/đã ghi sổ (`PACK_NOT_FOUND`) → gói là chu trình hiện hành (`Set Unit.active_cycle_id == cycle_id`, else `PACK_NOT_ACTIVE_CYCLE`) → `Pack.status == Packed` (`In Load` → `PACK_IN_OTHER_LOAD`; khác → `STATUS_INVALID_FOR_STATION`) → cổng `step_gate.check(su, "T5")` (T4 Đạt) → trùng trong danh sách (`PACK_ALREADY_SCANNED`) → phương pháp → loại gói → dung tích.
- Load ID `ME-YYMMDD-NN` (Courier New trên UI và nhãn); không nhập tay; `gs1.parse_scan` nhận `ME-\d{6}-\d{2}` là type `load`.
- Giờ hiển thị `dd/mm/yyyy HH:mm` 24 h Asia/Ho_Chi_Minh; số thập phân nhập trên kiosk chấp nhận dấu phẩy (`134,2`) và chấm, lưu Float.
