# FEAT-021 T2 Lô rửa (nạp · dỡ · kết quả) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** KTV khu bẩn quét QR máy rửa, nạp nhiều bộ đã qua cổng T1, bấm Hoàn thành nạp để hệ thống sinh mã lô `LR-YYMMDD-NN` và in nhãn QR lô; khi máy xong, người dỡ quét QR máy + QR lô, nhập (hoặc xác nhận) dữ liệu chu trình và áp một kết quả Đạt/Không đạt cho mọi bộ trong lô qua `core.step_gate` (SCR-06, UC-06).

**Architecture:** Module `Reprocessing` (M2) thêm DocType `Wash Batch` (+ 2 bảng con) và dịch vụ `tracecore/reprocessing/washing.py`; RPC mỏng `tracecore.v1.wash.*` theo khuôn `v1.pack` (`station_session` + `@idempotent` + `run_at_step`). Cổng T1→T2 và chuyển Xử lý lại dùng nguyên `core.step_gate` (không đổi trạng thái Set Unit ở nơi khác). Máy và chương trình đọc qua DB (không import `tracecore.equipment`); lô hóa chất đọc ERPNext `Batch` như `packing.resolve_ci_batch`. UI là lớp `T2Wash` trong Page `station` (ADR-002), nối như `T4Packing`.

**Tech Stack:** Frappe v15, Python 3.11, JS thuần trong Page `station`, Playwright for Python.

**Spec:** `docs/implementation-plan.md` §3 dòng FEAT-021; `docs/srs.md` FR-M2-03 (.1–.6), FR-M2-04 (.1–.7), FR-M2-24 (partial: .1, .3, .5, nguồn Nhập tay), FR-M2-25 (T2 record, Xử lý lại); `docs/use-cases.md` UC-06; `docs/ux-foundations.md` SCR-06; **mockup #17** `17 Giao dien theo vai tro v1_10 20260920.html` (màn T2: hàm `t2`, `t2scan`, `t2scanMachine`, `t2complete`, `t2unloadScan`, `t2unload`, `t2close`, `manualForm`, `batchCard`, `gatePanel`; dòng 269–274 và 382–401) — Task 6 bám mockup này; **BA toàn bộ** `TraceCore BA ToanBo v1_10 20260920.html`: UC-06 (dòng 3058), US-06 (4032), BRU-FLOW-004 (909), BRU-REP-002 (930), BRU-REP-015 (1010), BRU-REP-016 (1020), DT-WASHBATCH (4765), API-M2-02/03 (6850/6868), ma trận quyền DocType (7657–7669), TC-06-01/02 (7951/7964), WF-04 (9061); `docs/architecture.md` §5.3.1 (Wash Batch, DT-WASHBATCH), §5.3.3 (`LR-.YY.MM.DD.-.##`), ADR-005 (step gate), ADR-007 (`param_schema`), sơ đồ tuần tự dòng 770–799. ## Global Constraints

- Kế thừa Global Constraints của FEAT-001/018/003/038 (v15, không import chéo M1–M10, chỉ `core.step_gate` đổi trạng thái Set Unit, Audit Log append-only, RPC `tracecore.v1.<domain>.<action>`, `@idempotent` + `X-Idempotency-Key` + `client_ts` có offset, mã sinh ở server, chuỗi qua `_()`/`__()` + `vi.csv`, token `--tc-*`, lỗi chặn `alert-error` inline, TDD + `@bru`, coverage changed-code ≥ 70 %, `test_ignore` cho Link ERPNext/HRMS/User).
- Mã lô: `LR-YYMMDD-NN` (naming series `LR-.YY.MM.DD.-.##`, ngày theo giờ hệ thống `Asia/Ho_Chi_Minh`), ghi `Code Registry` prefix `LR` ref `Wash Batch`; `gs1.parse_scan` nhận `LR-\d{6}-\d{2}` thành loại `wash_batch`. Mã không nhập tay (FR-M2-03.2).
- Thứ tự kiểm khi nạp một bộ (trả lỗi đầu tiên): trạm đúng bước T2 → máy hợp lệ (tồn tại, loại máy, `Ready`) → mã quét là Set ID → bộ tồn tại → `step_gate.check(set, "T2")` → chưa Pass T2 → không ở lô khác. Bộ đã có trong danh sách đang quét không phải lỗi (`duplicate: true`).
