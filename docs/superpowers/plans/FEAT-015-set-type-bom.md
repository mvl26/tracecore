# FEAT-015 Loại bộ & BOM có phiên bản (ngày hiệu lực, so sánh 2 phiên bản), ảnh bộ đã xếp, hạn lưu theo loại gói, phiếu kiểm đếm PDF — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** R02/R10 khai báo Loại bộ dụng cụ trên Desk (SCR-02): tên, khoa sở hữu, phương pháp, loại gói mặc định (chỉ loại gói đã có hạn lưu), hạn lưu (mặc định từ loại gói, chỉ ghi đè ngắn hơn), cờ cấy ghép, thời gian lắp ráp chuẩn, 1–3 ảnh thực tế bộ đã xếp, BOM dụng cụ × số lượng theo thứ tự xếp. Lưu lần đầu tạo BOM phiên bản 1; mỗi lần sửa BOM (kèm ngày hiệu lực không ở quá khứ và lý do) tạo phiên bản mới, không sửa đè phiên bản cũ; bộ đang giữa chu trình giữ phiên bản cũ tới lần tiếp nhận T1 kế tiếp; so sánh hai phiên bản bất kỳ; in phiếu kiểm đếm PDF (tổng số dụng cụ, ảnh bộ, thứ tự xếp, DataMatrix của phiên bản BOM). Trạm/PDA đọc BOM qua `tracecore.v1.set_type.bom(set_type, version)` có cache và `etag`.

**Architecture:** Module Frappe `Instrument` (M1): mở rộng `Instrument Set Type` và `Set BOM Item` (khung FEAT-001/018, A-02) — **không thêm DocType** (S1, S6). Package `tracecore/instrument/` thêm `set_type.py` (luật phần đầu loại bộ, cơ số suy ra, sao chép), `bom_versions.py` (dòng BOM, tạo/kích hoạt/so sánh phiên bản, phiên bản áp dụng cho bộ), `shelf_life.py` (hạn lưu loại gói / loại bộ, BRU-REP-009), `count_sheet.py` (ngữ cảnh + HTML + PDF phiếu kiểm đếm); `media.py` (FEAT-014) được tổng quát hóa theo (DocType, trường) để ảnh loại bộ dùng đúng luật ảnh dụng cụ, không chép mã; `bom.py` giữ `lines()` và đổi nguồn phiên bản của `pack_context` sang phiên bản đã ghim của bộ. Ghim phiên bản: `core.step_gate.start_cycle` gọi hook mới `tracecore_cycle_bom_version` (M1 trả số phiên bản) và ghi `Set Unit.cycle_bom_version` cùng nhóm trường vòng đời. Mã DataMatrix phiếu kiểm đếm sinh ở `core.gs1`. Print Format Jinja chuẩn `TC Count Sheet` + PDF qua `frappe.utils.pdf.get_pdf` (wkhtmltopdf có sẵn của Frappe v15), ảnh nhúng base64, không tải gì từ mạng. RPC mỏng: `tracecore/v1/set_type.py` (GET, đọc) và `tracecore/v1/set_type_admin.py` (POST, `@idempotent`). Giao diện Desk form + Client Script (ADR-002). Không import chéo M1–M10: M1 đọc `Pack`/`Item` theo tên DocType; M2 (T4) không bị sửa.

**Tech Stack:** Frappe v15 (Print Format Jinja, `frappe.utils.pdf.get_pdf` → wkhtmltopdf 0.12.6, `frappe.cache`, scheduler cron), Pillow (đã có: thumbnail, ảnh in), `pylibdmtx` (đã có: DataMatrix PNG qua `gs1.encode_datamatrix_png`), `pypdf` (đã có: đọc PDF trong test), Python 3.11, Desk Client Script, Playwright for Python.
