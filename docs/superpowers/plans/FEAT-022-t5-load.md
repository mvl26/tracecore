# FEAT-022 T5 Nạp mẻ tiệt khuẩn — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** KTV tiệt khuẩn (R05) quét QR máy tiệt khuẩn, chọn chương trình, quét nối tiếp Cycle ID từng gói (server kiểm cổng T4, tương thích gói – chương trình, dung tích, gói ở mẻ khác), bấm (hoặc quét) Hoàn thành nạp để hệ thống sinh mã mẻ `ME-YYMMDD-NN`, chuyển gói sang Trong mẻ và in nhãn QR mẻ; khi máy chạy xong, người vận hành nhập tay dữ liệu chu trình theo `param_schema` của chương trình, đính ảnh bản in, tick xác nhận và quét lại thẻ, mẻ sang Hoàn tất chu trình (SCR-09 STN, SCR-35 PDA, UC-09).

**Architecture:** Module `Reprocessing` (M2) thêm DocType `Sterilization Load` + bảng con `Load Pack` và dịch vụ `tracecore/reprocessing/sterilizing.py`; RPC mỏng `tracecore.v1.load.*` theo khuôn `v1.wash` (`station_session` + `@idempotent` + `run_at_step`). Cổng T4 → T5 kiểm bằng `core.step_gate.check(set, "T5")`; nạp mẻ **không** ghi cổng T5 và không đổi trạng thái Set Unit (cổng T5 ghi khi giải phóng, FEAT-023). Máy và chương trình đọc qua DB (không import `tracecore.equipment`). Nhãn QR mẻ qua `core.print` (mẫu `Object label - Sterilization Load`). Test ngày / kiểm định là hook rỗng `tracecore_load_equipment_checks` (stub "máy sẵn sàng" đến FEAT-040). UI là lớp `T5Load` trong Page `station` (ADR-002), cùng lớp chạy bố cục PDA một cột khi màn ≤ 480 px (SCR-35).

**Tech Stack:** Frappe v15, Python 3.11, JS thuần trong Page `station`, Playwright for Python.
